# Tech tree from Wikipedia links (pilot)

Static build of a pilot viewer: the top 1,500 technologies in our dataset (ranked by body-text Wikipedia links from
later technologies) and up to 3 earlier technologies linked in each article, coloured by domestic and foreign links.
Images are Wikipedia lead or early-version images, loaded from Wikimedia.

The viewer code is adapted from the Historical Tech Tree by Étienne Fortier-Dubois
(https://github.com/etiennefd/hhr-tech-tree), MIT License (see LICENSE). That project's dataset and images are not
included.
